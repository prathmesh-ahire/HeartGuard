Algorithm ALG-17: Noise and duration robustness analysis
PV-MEPCG / PulseVision  |  T99.4  |  objective O4

Purpose: Two questions kept apart: how the model does on recordings that are already noisy or short (observational), and what happens when noise is added or a recording is clipped (interventional).
Input:   stored out-of-fold predictions, PP-08 quality flags, a stratified PhysioNet sample
Output:  metrics per quality group and duration band, and per SNR level and clip length

Algorithm
   1  observational: attach each prediction's quality group (clean, noisy, low_quality_other); a prediction with no flag is an error
   2      score every (model, fold, group); a slice under 30 records is kept with reported = false, never dropped
   3  the same per duration band (short, medium, long)
   4  interventional: sample <- PhysioNet records stratified over (subset, class)
   5  model <- the final configuration refitted WITHOUT every sampled subject, so no score is in-sample
   6  for each record and each SNR level in inf, 20, 15, 10, 5, 0:
   7      rng <- seeded by [int(seed), int(zlib.crc32(uid.encode("utf-8"))), _level_key(level)], so resuming or the worker count changes nothing
   8      noisy <- raw + white Gaussian noise of power power / (10.0 ** (float(snr_db) / 10.0)); the infinite level is the untouched control
   9      filter, normalize and extract all features (ALG-03, ALG-04); record the SNR that survived the band-pass
  10  for each record and each clip length in inf, 10, 5, 3: clip the RAW signal from a seeded random window, start int(rng.integers(0, x.size - want + 1)); then the same chain
  11  checkpoint after every batch of records; a resumed run reproduces bit for bit
  12  score each level with the held-out model; delta against the control
  13  score each clip length with the same held-out model; delta against the full recording

Notes
  A gap in the observational half is an association; a gap in the sweep is causal for additive white noise only, which is not the noise a stethoscope picks up. Neither is quoted as the other.
