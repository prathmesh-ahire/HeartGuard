Algorithm
   1  objectives <- the 6 locked objectives, verbatim, each with digest hashlib.sha256(wording.encode("utf-8")).hexdigest()
   2  check the wording against the blueprint PDF
   3  T29: for each objective:
   4      refuse to build if a named module or evidence file does not exist
   5      outstanding <- required evidence whose glob matches nothing (outputs/13_figures_diagrams/G14_*.png, outputs/**/*literature*.csv, outputs/13_figures_diagrams/G16_*.png); status <- "partial" if outstanding else "evidence produced"
   6  T30: for each objective:
   7      finding <- numbers read from the named tables at build time and formatted by the table engine; none typed
   8      verdict <- the objective's stated rule applied to those numbers; the rule and the bounding limitation travel in the row
   9  build both tables through the table engine
  10  register every written file in the evidence index; a missing file is recorded as missing, never ok

Notes
  The status is re-derived from the filesystem on every build, so an objective leaves partial by itself when its evidence lands.
