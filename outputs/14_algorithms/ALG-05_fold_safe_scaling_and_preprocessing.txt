Algorithm ALG-05: Fold-safe scaling and preprocessing
PV-MEPCG / PulseVision  |  T98.3  |  objective O1

Purpose: Everything that learns from data -- imputation, scaling, selection, class weighting -- is fitted on the training fold only, as steps of one pipeline.
Input:   feature matrix X, labels y, the stored fold map (DA-07)
Output:  per-fold out-of-fold predictions from a pipeline that never saw its test rows

Algorithm
  1  for each (repeat, fold) of the stored map (5 x 5, grouped on subject_id), loaded never re-derived:
  2      assert no subject appears in both train and test
  3      P <- Pipeline[imputer (median), scaler (standard), selector if enabled (false), clone(estimator)]
  4      if the estimator accepts class_weight: set it to balanced; otherwise leave imbalance to the estimator (ALG-10's wrapper)
  5      if resampling is enabled: refuse -- it must happen inside the fold
  6      fit P on X[train], y[train]: the medians, means, variances and selector scores are learned from training rows only
  7      predict X[test] through P: the test rows are transformed, never fitted
  8  expose the learned statistics for the fold-safety tests
