Algorithm ALG-14: Multiclass evaluation workflow
PV-MEPCG / PulseVision  |  T99.2  |  objective O6

Purpose: Each multiclass task keeps its own label space and is scored with macro-F1 and per-class recall, with a check that the model actually emits every class.
Input:   one task's feature matrix and stored fold map; its declared labels
Output:  per-fold and aggregate multiclass metrics, per-class recall, coverage flags

Algorithm
   1  for each task in pascal_a (EXP-B1), pascal_b (EXP-B2), circor_murmur (EXP-C1): labels <- that task's own label space, never merged with another's
   2  drop only rows whose label the variant does not declare; refuse any other shrinkage
   3  folds <- the task's stored map (PASCAL A repeated_5x2_stratified: 5 x 2; PASCAL B grouped_5fold)
   4  for each model and fold: leakage checks, fit and predict exactly as in ALG-13
   5      per class c: precision, recall, F1 and support; accuracy, balanced accuracy, weighted F1
   6      macro-F1 <- f1_score(true, pred, labels=ordering, average="macro", zero_division=0)
   7      one-vs-rest AUC <- roc_auc_score(true, proba, multi_class="ovr", average="macro", labels=ordering) when every class is present in the fold; NaN otherwise
   8  aggregate mean and sample SD over folds, as in ALG-13
   9  coverage <- classes the model ever emitted; missing classes named; degenerate if len(emitted) <= 1
  10  record-level intervals: bootstrap within each repeat (2000 draws, seed int(seed) + int(repeat)), averaged over repeats

Notes
  Reported for every multiclass run: accuracy, macro_f1, weighted_f1, balanced_accuracy, per_class_precision, per_class_recall, ovr_auc, mcc. Search objective: macro_f1.
  PASCAL's artifact class is a recording-quality label, so a four-class PASCAL A result is never described as a four-class cardiac classifier.
