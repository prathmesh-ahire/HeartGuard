Algorithm
   1  members, inner splits and out-of-fold probabilities oof exactly as in ALG-11 (M3, M4, M5, weights optimized, inner_cv 3)
   2  grid <- every non-negative weight vector on the simplex at resolution 0.05, from an integer lattice
   3  if the exact equal-weight vector is not on the lattice: add it, np.vstack([centre[None, :], lattice]); |grid| = 232
   4  if the task is binary:
   5      for each candidate w: t(w) <- select_threshold(fuse(oof, w)); score(w) <- balanced_accuracy = 0.5 x sensitivity + 0.5 x specificity at t(w) -- weights and threshold chosen jointly
   6      b <- argmax score; SE <- exact binomial standard error of b's objective, (a**2) * sensitivity * (1.0 - sensitivity) / n_positive + (b**2) * specificity * (1.0 - specificity) / n_negative, square-rooted
   7      margin <- 1 x SE (one_standard_error)
   8      within <- candidates with scores >= best - margin - 1e-12; w* <- the one closest to equal weights in L2, np.linalg.norm(grid[within] - uniform, axis=1)
   9  else (multiclass): score(w) <- f1_score(targets, predicted, average="macro", zero_division=0) + balanced_accuracy_score(targets, predicted) on the fused argmax; w* <- exact ties only (margin 0), broken toward equal weights
  10  record the candidate count, how many fell within the margin, the best and chosen scores, and the argmax weights beside w*
  11  t* <- select_threshold on fuse(oof, w*), as in ALG-11; refit every member on the whole training fold
  12  predict as ALG-11 with w* in place of equal weights

Notes
  A grid, not a gradient optimiser: balanced_accuracy is a step function of the weights, so it has zero gradient almost everywhere. The grid needs no seed.
  The one-standard-error rule is a selection rule fixed before any result; it is never tuned to a score. When no candidate beats the noise, M7 returns equal weights and equals M6.
