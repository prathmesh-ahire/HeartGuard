Operating pointOn a TWO-class task the deployed bundle carries no in-fold threshold, and every stored prediction in the experiment that backs it is the plain argmax, so inference decides at 0.5 -- which is what reproduces those results. A multiclass task has no single operating point at all: the highest probability wins. Each result below states which rule it used.

Scope

Two datasets, two label spaces, one page

  • PASCAL A and PASCAL B are separate tasks with separate models. This page offers both and merges neither: a recording is scored against one vocabulary or the other, never against their union.
  • Four PASCAL Dataset A categories. `artifact` is a RECORDING-QUALITY label, not a cardiac class, so this is not a four-class cardiac classifier.
  • Academic screening and decision-support prototype. Not a diagnostic device and not a substitute for clinical assessment.
  • A prediction is reported low-confidence when the gap between the top two class probabilities is below this margin. The margin, not a probability floor: on a three-class task 0.40 is a comfortable win and on a two-class task it is a coin flip that landed.
