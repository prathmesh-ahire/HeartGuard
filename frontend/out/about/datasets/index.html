Dataset Overview

Four public phonocardiogram corpora, audited file by file rather than taken from their documentation. Where the published counts and the files on disk disagreed, the files won and the discrepancy is recorded.
Every audited file is counted in 'files'; 'modelled' is the supervised subset the experiments actually use, which is smaller than the corpus for three of the four families. Any total taken over these rows has to say which of the two populations it counted.
